# Support

Kurulum, kullanım ve yeniden üretilebilir ürün hataları için GitHub issue şablonlarını kullanın. İşletim sistemi, Docker sürümü, AgentGuard commit'i, beklenen davranış ve secretsiz hata özetini ekleyin.

OAuth token, agent key, cookie, connector credential, gerçek e-posta içeriği veya müşteri verisini issue'ya koymayın. Güvenlik etkisi olabilecek bir davranışı public issue yerine [SECURITY.md](SECURITY.md) üzerinden özel bildirin.

Bu açık kaynak pilot sürüm için garantili destek veya yanıt süresi yoktur. Kurumsal deployment, uyumluluk ve SLA ihtiyaçları mevcut repository desteğinin kapsamı dışındadır.
